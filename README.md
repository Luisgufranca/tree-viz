<div align="center"> <h1>🌳 <strong>treeviz</strong></h1> <h3>Gerador e Visualizador de Árvores Binárias de Pesquisa (ABP)</h3> <p>Projeto em C para manipular e visualizar árvores binárias de pesquisa, com saída gráfica automática via Graphviz.</p> </div>
<h2>🔧 Tecnologias utilizadas</h2> <ul> <li><strong>C</strong> — lógica da ABP e execução</li> <li><strong>Graphviz</strong> — geração do arquivo DOT e renderização da imagem</li> <li><strong>Makefile</strong> — compilação automatizada</li> <li><strong>Git</strong> — versionamento do projeto</li> </ul>
<h2>🚀 Como compilar</h2> <p>Basta usar:</p> <p><strong>make</strong></p> <p>Isso gera o executável <strong>treeviz</strong>.</p>
<h2>▶️ Como usar</h2> <p>Execute:</p> <p><strong>./treeviz [opções]</strong></p> <ul> <li><strong>-insere X Y Z...</strong> — insere múltiplos valores</li> <li><strong>-remove X Y Z...</strong> — remove os valores informados</li> <li><strong>-imprime</strong> — mostra os nodos em ordem crescente</li> <li><strong>-help</strong> — exibe o guia de comandos</li> </ul>
<h2>💡 Exemplo rápido</h2> <p><strong>./treeviz -insere 8 3 10 1 6 -remove 3 -imprime</strong></p>
<h2>🖼 Saída visual</h2> <p>Ao finalizar (exceto com <strong>-help</strong>), o programa gera automaticamente:</p> <ul> <li><strong>treeviz.dot</strong> — descrição da árvore</li> <li><strong>treeviz.png</strong> — imagem gerada via Graphviz</li> </ul> <p>A imagem é aberta automaticamente no visualizador padrão do sistema.</p>
